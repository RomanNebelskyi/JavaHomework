# JavaHomework

Collection of Java homework assignments covering core language concepts — from basic syntax to collections, regex, OOP, and comparators.

## Topics Covered

| Module | Topic |
|--------|-------|
| hw2–hw5 | Core Java syntax, conditionals, loops |
| hw6–hw9 | Arrays, strings, methods |
| hw11 | Regular expressions |
| hw12 | ArrayList, collections |
| hw13–hw14 | Comparators (`Comparator`, `Comparable`) |
| hw15–hw16 | OOP: classes, inheritance, encapsulation |
| hw18–hw21 | Advanced topics |

## Structure

```

├── hw{number}/     — Individual homework module
├── homework/       — Supplementary assignments
└── README.md
```

Each module contains standalone `.java` files with the solution and a `main()` method for direct execution.

## Requirements

- Java 8+
- Any Java IDE (IntelliJ IDEA recommended) or CLI compilation
